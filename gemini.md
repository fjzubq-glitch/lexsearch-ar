# LexSearch Gold: Reglas de Oro de Gemini

Este documento constituye el manual de estilo permanente para el desarrollo y mantenimiento de la plataforma LexSearch Gold. Estas reglas son innegociables para mantener la identidad visual "Azure Gold".

## 1. Paleta de Colores Crítica
- **Fondo Global (Azure Background):** `#F0F7FF`
- **Texto de Lectura (Obsidian Black):** `#050505`
- **Acento Institucional (Azure Blue):** `#2563EB` (utilizado con moderación en botones activos y enlaces).

## 2. Precisión Estructural
- **Bordes Quirúrgicos:** Todos los contenedores, botones y tarjetas deben utilizar un borde de `0.5px`. Se prohíbe el uso de bordes de 1px o superiores.
- **Geometría Square:** Los botones y campos de entrada deben tener un `border-radius: 0px`. La estética es rectilínea y de precisión institucional.
- **Transiciones:** El uso de `backdrop-blur` es preferible para elementos flotantes (navbars, modales) para mantener la profundidad sin ruido visual.

## 3. Tipografía y Espaciado
- **Serif Italic:** Reservada para títulos principales e interrogaciones jurídicas, evocando la elegancia académica.
- **Sans Uppercase:** Utilizada para metadatos, etiquetas y navegación secundaria con un `letter-spacing` amplio (`tracking-[0.2em]` o superior).

## 4. Filosofía "Zero Noise"
- Evitar sombras pesadas; utilizar bordes finos y cambios sutiles de fondo para denotar jerarquía.
- Mantener el aire (white space) como prioridad para facilitar la lectura de textos legales complejos.
