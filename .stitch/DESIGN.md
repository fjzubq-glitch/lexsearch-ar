# LexSearch Gold: Design System (Azure Gold Edition)

This design system ensures consistency across the LexSearch Gold platform using the Stitch Protocol.

## 1. Core Palette
- **Fondo Global (Azure Background):** `#F0F7FF`
- **Texto de Lectura (Obsidian Black):** `#050505`
- **Acento Institucional (Azure Blue):** `#2563EB` (utilizado con moderación).

## 2. Structural Precision
- **Bordes Quirúrgicos:** Todos los contenedores, botones y tarjetas deben utilizar un borde de `0.5px`. NO usar 1px.
- **Geometría Square:** Botones y campos de entrada con `border-radius: 0px`. Estética rectilínea e institucional.
- **Backdrop Blur:** Utilizar para elementos flotantes (navbars, modales).

## 3. Typography
- **Serif Italic:** Para títulos principales e interrogaciones jurídicas (Elegancia Académica).
- **Sans-Serif (Manrope):** Para cuerpos de texto, metadatos y navegación (Tracking amplio `0.2em`). Clean and professional.

## 4. Filosofía "Zero Noise"
- Espacios en blanco generosos.
- Sin sombras pesadas.

## 5. Metadata
- **Project Name:** LexSearch Gold
- **Target Device:** DESKTOP
